# Personal Portfolio

A personal portfolio website built to showcase my projects, skills, certificates, and contact information. The goal of this portfolio is to have one place where people can learn about me, see the projects I've worked on, and easily get in touch.

## Features

* Responsive design for desktop and mobile
* Clean and minimal UI
* Projects section with live demos and GitHub links
* Skills section with official technology logos
* Certificates section
* Contact section with social links
* Smooth scrolling navigation

## Built With

* React
* Vite
* CSS
* React Icons
  
## A Note
This is my first ever portfolio. I used AI to help me understand concepts, debug problems, and learn new things, but I made sure to understand the code before adding it to my project. I enjoyed it a lot while making it because I love creating new things!
